# Brass: Birmingham - Online Prototype

This repository will host an online implementation of the board game "Brass: Birmingham" (prototype).

Goals:
- Server-authoritative online multiplayer implementation (real-time) with AI players.
- Exact game rules implementation.
- Public access: anyone can join games.
- Non-commercial, community-hosted on user's server.

Workflow:
1. Create `online-prototype` branch with initial scaffold (frontend + backend).
2. Implement server-side game engine and AI.
3. Connect frontend (React) to backend (Node/Express + Socket.io).
4. Add persistence (PostgreSQL) and deployment instructions.

Note: This project contains no original artwork from the published game; use only original or freely licensed assets.
